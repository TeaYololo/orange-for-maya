# Orange 1.2.0

This release adds the requests from [#11](https://github.com/TeaYololo/orange-for-maya/issues/11) and the follow-up on [#9](https://github.com/TeaYololo/orange-for-maya/issues/9). Thanks again to @5Grn.

## New

- **Array rotation and scale (#11).** The Array card has **Rotation (per copy)** and **Scale (per copy)** fields: every copy is rotated / scaled by that much relative to the previous one, like Maya's Duplicate Special. They combine with the relative and constant offsets, so a radial array is just a rotation plus an offset. No extra object is added to the scene: Maya's built-in `composeMatrix` node feeds the Array's Object Offset matrix, and if you also pick an offset object the two are combined. Setting the values back to 0 / 1 removes the helper node, and removing the Array removes it too.
- **Origin dot (#9).** The origin of the selected objects (and of the object in edit mode) is marked with Maya's pivot display and hidden again when the selection changes. It doesn't add undo steps, doesn't mark the scene as modified, and leaves pivot displays you turned on yourself alone. It can be turned off in Settings → Viewport.
- **F frames the selection in object mode (#9).** F does nothing in Blender's object mode, so in Orange it now works like Maya's F: the camera zooms to the selection and orbits around it (Numpad . does the same). In edit mode F still fills.

## Testing

Pure tests (109) and Maya 2027 headless tests (317) pass on Windows, including new tests that check the Array geometry with rotation / scale and the origin display. The origin display uses Maya's own pivot drawing, so it looks like Maya's pivot icon rather than Blender's dot.

Install by unzipping `Orange-1.2.0.zip` and dragging `drag_drop_install.py` onto a Maya viewport, or use **Orange → Check for updates** inside Maya.
