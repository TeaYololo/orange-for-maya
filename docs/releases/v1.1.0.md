# Orange 1.1.0

This release fixes the bugs reported in [#7](https://github.com/TeaYololo/orange-for-maya/issues/7) and [#8](https://github.com/TeaYololo/orange-for-maya/issues/8), fixes *Orbit Around Selection*, and adds several of the requests from [#6](https://github.com/TeaYololo/orange-for-maya/issues/6) and [#9](https://github.com/TeaYololo/orange-for-maya/issues/9). Thanks to @5Grn for the detailed reports.

## Fixes

- **F3 search could not be closed on macOS (#7).** A borderless window can never become the key window on macOS, so the F3 palette never received keyboard focus (Esc did nothing) and was never activated (so its close-on-click-outside never fired). On macOS the palette now opens with a title bar. In addition, Orange's own event filter closes the palette on Esc and on any click outside it, on every platform; the outside click still reaches Maya.
- **Bevel corners were filled with a single n-gon (#8).** Ctrl+B now creates the bevel with `subdivideNgons`, so multi-segment corners are split into quads like Maya's own Bevel and Orange's Bevel modifier.
- **Orbit Around Selection did nothing (#9).** The setting turned on Maya's `objectTumble`, which means "tumble around the object under the cursor" and has nothing to do with the selection. It now uses Maya's *tumble pivot* with *Auto-set pivot*, so every selection moves the orbit center to the selection. Turning it off restores Maya's previous tumble settings.

## New

- **Bevel profile with the mouse (#9).** During Ctrl+B, **P** now ties the profile to the mouse instead of stepping through fixed values: move the mouse up / down to change it continuously (Shift for precision, Ctrl to snap, or type a number). Press P again to go back to the width. In Maya the profile is the bevel `depth` (-1 to 1).
- **Select through in Wireframe / X-Ray (#6).** Like Blender, Solid view selects only what is visible, and switching to Wireframe or X-Ray with Orange also selects what is behind (Maya's camera based selection). Can be turned off in Settings → Viewport. Maya's previous selection setting is restored when Orange is uninstalled.
- **Proportional editing like Blender (#9).** **O** no longer leaves Maya's soft select on all the time: the colored falloff only shows while you move, rotate or scale, and switches off when the operation ends. Use the mouse wheel during the operation to change its size.
- **Ctrl + . edits the origin (#9).** Moves / rotates the selected object's origin (pivot) freely with the move tool's pivot edit mode; press Ctrl + . again to go back. This is the Maya equivalent of Blender's *Affect Only Origins* (D / Insert in Maya).

## Not in this release

- **Clamp Overlap on C (#9):** Maya's bevel (`polyBevel3`) has no clamp option, so C still toggles chamfer.
- **Origin dot (#9):** Ctrl + . shows the pivot while editing it; a permanent dot for every selected object needs custom viewport drawing and is left for a later release.
- **Subdivision wireframe (#9):** since 1.0 the Subdivision modifier is a real `polySmooth` history node so it can be stacked with Mirror / Array, and Maya draws its real edges. Blender's "optimal display" would need custom drawing.
- **Selectable 3D cursor (#9):** as in Blender, the cursor is moved with Shift+right click and Shift+S, not selected.
- **Modifier panel in the right dock (#9):** once the panel has been docked on the right, Maya restores it there on every start (since 1.0.2).

## Testing

Pure tests (109) and Maya 2027 headless tests (298) pass on Windows. The macOS F3 change could not be tested on a real Mac yet, and the Orbit Around Selection and Ctrl + . changes follow Maya's documented tool flags but were not verified by hand in the Maya UI. Please report anything that does not behave as described.

Install by unzipping `Orange-1.1.0.zip` and dragging `drag_drop_install.py` onto a Maya viewport, or use **Orange → Check for updates** inside Maya.
