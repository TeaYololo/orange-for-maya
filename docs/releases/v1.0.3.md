# Orange 1.0.3

This release addresses the macOS Maya startup crash reported in [issue #4](https://github.com/TeaYololo/orange-for-maya/issues/4).

- On macOS, Orange now installs its Qt event filter on QWidget instances instead of QApplication. QtWebEngine internal QObject events therefore do not pass through the PySide application-wide filter implicated by the crash report.
- Orange scans for newly created widgets and removes its per-widget filters during shutdown.
- The startup guard now watches for late startup crashes for 60 seconds.

The macOS-specific filter path was simulated with Maya 2027 on Windows. Native macOS Maya testing has not yet been possible, so this release still needs confirmation on the reporter's Mac.

Install by unzipping `Orange-1.0.3.zip` and dragging `drag_drop_install.py` onto a Maya viewport. If an older installation still prevents Maya from opening, remove the old `modules/orange` folder and `modules/orange.mod` first.
